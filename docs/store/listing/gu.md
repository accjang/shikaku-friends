## description
બોર્ડને લંબચોરસમાં વહેંચો — દરેકમાં એક આંકડો, અને એ આંકડો કહે છે કે લંબચોરસ કેટલો મોટો!

શિકાકુ ફ્રેન્ડ્સ જાપાનની જાણીતી લોજિક પઝલ "શિકાકુ"ને ક્યૂટ પ્રાણી મિત્રો સાથે લઈ આવે છે.

■ બે સરળ નિયમ
· બોર્ડને લંબચોરસમાં વહેંચો.
· દરેક લંબચોરસમાં ફક્ત એક જ આંકડો, જે તેનાં ખાનાંની સંખ્યા જેટલો હોય.

■ ખાસિયતો
· ખેંચીને દોરો, ટૅપ કરીને ભૂંસો
· મીની, પાંડા, સસલુ, શિબા અને બતકુ હલનચલન કરે છે, હિંમત આપે છે — તમારો સાથી પસંદ કરો
· 200 સ્ટેજ, અને દરેક પઝલનો ઉકેલ ફક્ત એક જ
· સ્ટેજ પૂરા કરીને સજાવટ ભેગી કરો અને મિત્રોનું ગામ બનાવો
· બોર્ડ પૂરું કરીને છુપાયેલું ચિત્ર શોધો
· રોજ નવી પઝલ અને સતત 7 દિવસનાં ઇનામ — તમારું પરિણામ શેર કરો
· ઉતાવળ કરાવતું ટાઇમર નથી, ઇન્ટરનેટ વગર પણ રમી શકાય
