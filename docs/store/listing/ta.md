## description
பலகையைச் செவ்வகங்களாகப் பிரியுங்கள் — ஒவ்வொன்றிலும் ஒரு எண், அந்த எண்ணே அதன் அளவு!

ஜப்பானின் புகழ்பெற்ற லாஜிக் புதிர் "ஷிகாகு"வை அழகான விலங்கு நண்பர்களுடன் கொண்டுவருகிறது ஷிகாகு ஃப்ரெண்ட்ஸ்.

■ இரண்டே எளிய விதிகள்
· பலகையைச் செவ்வகங்களாகப் பிரியுங்கள்.
· ஒவ்வொரு செவ்வகத்திலும் சரியாக ஒரு எண், அது அதன் கட்டங்களின் எண்ணிக்கைக்குச் சமம்.

■ சிறப்பம்சங்கள்
· இழுத்து வரையுங்கள், தட்டி அழியுங்கள்
· கிட்டி, பாண்டா, பன்னி, ஷிபா, டக்கு அசைந்து உற்சாகப்படுத்துவார்கள் — உங்கள் நண்பனைத் தேர்ந்தெடுங்கள்
· 200 Stages, ஒவ்வொரு புதிருக்கும் சரியாக ஒரே தீர்வு
· Stage முடிக்கும்போது அலங்காரங்களைச் சேகரித்து நண்பர்களின் கிராமத்தைக் கட்டுங்கள்
· பலகையை முடித்தால் மறைந்திருக்கும் படம் தெரியும்
· தினமும் புதிய இன்றைய புதிர், 7 நாள் தொடர் பரிசுகள் — முடிவைப் பகிருங்கள்
· பதற வைக்கும் டைமர் இல்லை, இணையம் இல்லாமலும் விளையாடலாம்
