## description
ಬೋರ್ಡನ್ನು ಆಯತಗಳಾಗಿ ವಿಭಾಗಿಸಿ — ಪ್ರತಿಯೊಂದರಲ್ಲೂ ಒಂದು ಸಂಖ್ಯೆ, ಆ ಸಂಖ್ಯೆಯೇ ಅದರ ಅಳತೆ!

ಜಪಾನಿನ ಪ್ರಸಿದ್ಧ ಲಾಜಿಕ್ ಪಜಲ್ "ಶಿಕಾಕು"ವನ್ನು ಮುದ್ದಾದ ಪ್ರಾಣಿ ಫ್ರೆಂಡ್ಸ್ ಜೊತೆ ತಂದಿದೆ ಶಿಕಾಕು ಫ್ರೆಂಡ್ಸ್.

■ ಎರಡೇ ಸುಲಭ ನಿಯಮಗಳು
· ಬೋರ್ಡನ್ನು ಆಯತಗಳಾಗಿ ವಿಭಾಗಿಸಿ.
· ಪ್ರತಿ ಆಯತದಲ್ಲೂ ಸರಿಯಾಗಿ ಒಂದು ಸಂಖ್ಯೆ, ಅದು ಅದರ ಚೌಕಗಳ ಎಣಿಕೆಗೆ ಸಮ.

■ ವಿಶೇಷತೆಗಳು
· ಡ್ರ್ಯಾಗ್ ಮಾಡಿ ಬರೆಯಿರಿ, ಟ್ಯಾಪ್ ಮಾಡಿ ಅಳಿಸಿ
· ಕಿಟ್ಟಿ, ಪಾಂಡಾ, ಬನ್ನಿ, ಶಿಬಾ, ಬಾತುಮರಿ ಓಡಾಡುತ್ತಾ ನಿಮ್ಮನ್ನು ಹುರಿದುಂಬಿಸುತ್ತವೆ — ನಿಮ್ಮ ಜೊತೆಗಾರನನ್ನು ಆರಿಸಿ
· 200 Stages, ಪ್ರತಿ ಪಜಲ್‌ಗೂ ಸರಿಯಾಗಿ ಒಂದೇ ಉತ್ತರ
· Stages ಮುಗಿಸುತ್ತಾ ಅಲಂಕಾರಗಳನ್ನು ಸಂಗ್ರಹಿಸಿ ಫ್ರೆಂಡ್ಸ್ ಹಳ್ಳಿ ಕಟ್ಟಿ
· ಬೋರ್ಡ್ ಮುಗಿಸಿದರೆ ಅಡಗಿದ ಚಿತ್ರ ಕಾಣಿಸುತ್ತದೆ
· ಪ್ರತಿದಿನ ಹೊಸ ದಿನದ ಪಜಲ್, 7 ದಿನದ ಸ್ಟ್ರೀಕ್ ಬಹುಮಾನಗಳು — ನಿಮ್ಮ ಫಲಿತಾಂಶ ಶೇರ್ ಮಾಡಿ
· ಒತ್ತಡ ಕೊಡುವ ಟೈಮರ್ ಇಲ್ಲ, ಆಫ್‌ಲೈನ್‌ನಲ್ಲೂ ಆಡಬಹುದು
