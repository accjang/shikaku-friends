## description
照著數字畫出方塊，把盤面分割開來吧！

方塊朋友是一款和可愛動物朋友們一起挑戰日本經典邏輯謎題「Shikaku（四角）」的遊戲。

■ 規則只有兩條
· 把盤面分成長方形。
· 每個長方形裡剛好有一個數字，數字就是它的格數。

■ 遊戲特色
· 拖曳畫方塊，點一下就能擦掉
· 貓咪、熊貓、兔兔、柴柴、小鴨會動來動去幫你加油，還能選擇同行夥伴
· 200個關卡，每題都只有唯一解答
· 過關收集道具，布置朋友們的村莊
· 解完盤面就會出現隱藏的圖畫
· 每天都有新的「每日謎題」，連續7天獎勵，還能分享成績
· 沒有時間壓力，離線也能玩
