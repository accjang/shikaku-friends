## description
ബോർഡിനെ ചതുരങ്ങളായി വിഭജിക്കൂ — ഓരോന്നിലും ഒരു നമ്പർ, ആ നമ്പറാണ് അതിന്റെ വലുപ്പം!

ജപ്പാനിലെ പ്രശസ്ത ലോജിക് പസിൽ "ഷിക്കാകു" ഓമനത്തമുള്ള മൃഗ കൂട്ടുകാർക്കൊപ്പം എത്തിക്കുകയാണ് ഷിക്കാകു ഫ്രണ്ട്സ്.

■ രണ്ടേ രണ്ട് എളുപ്പ നിയമങ്ങൾ
· ബോർഡിനെ ചതുരങ്ങളായി വിഭജിക്കൂ.
· ഓരോ ചതുരത്തിലും കൃത്യം ഒരു നമ്പർ, അത് അതിലെ കള്ളികളുടെ എണ്ണത്തിന് തുല്യം.

■ സവിശേഷതകൾ
· ഡ്രാഗ് ചെയ്ത് വരയ്ക്കൂ, ടാപ്പ് ചെയ്ത് മായ്ക്കൂ
· കിറ്റി, പാണ്ട, ബണ്ണി, ഷിബ, താറാക്കുഞ്ഞ് ഓടിനടന്ന് നിങ്ങളെ പ്രോത്സാഹിപ്പിക്കും — നിങ്ങളുടെ കൂട്ടുകാരനെ തിരഞ്ഞെടുക്കൂ
· 200 Stages, ഓരോ പസിലിനും കൃത്യം ഒരൊറ്റ ഉത്തരം
· Stages ക്ലിയർ ചെയ്ത് അലങ്കാരങ്ങൾ ശേഖരിച്ച് ഫ്രണ്ട്സിന്റെ ഗ്രാമം ഒരുക്കൂ
· ബോർഡ് പൂർത്തിയാക്കിയാൽ ഒളിഞ്ഞിരിക്കുന്ന ചിത്രം തെളിയും
· എല്ലാ ദിവസവും പുതിയ ഇന്നത്തെ പസിൽ, 7 ദിവസത്തെ സ്ട്രീക്ക് സമ്മാനങ്ങൾ — റിസൾട്ട് ഷെയർ ചെയ്യൂ
· ടെൻഷൻ അടിപ്പിക്കുന്ന ടൈമർ ഇല്ല, ഓഫ്‌ലൈനിലും കളിക്കാം
