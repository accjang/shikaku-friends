## description
数字の数だけ四角を描いて、盤面を分けよう！

シカクフレンズは、日本生まれの人気ロジックパズル「四角に切れ（シカク）」を、かわいい動物のなかまたちと楽しめるゲームです。

■ ルールはたった2つ
· 盤面を長方形に分けます。
· 長方形には数字がちょうど1つ。その数字が長方形のマスの数です。

■ ここが楽しい
· ドラッグで四角を描いて、タップで消せる
· ネコ・パンダ・ウサギ・シバ・アヒルが動いて応援してくれる。いっしょに行くなかまも選べます
· 200ステージ、どのパズルも答えはひとつだけ
· ステージをクリアするたびにアイテムを集めて、なかまのむらを飾ろう
· 全部解くと隠れていた絵が登場！
· 毎日新しい「今日のパズル」、7日連続ボーナス、結果をシェア
· 時間制限なしでのんびり、オフラインでも遊べます
