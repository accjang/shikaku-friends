## description
Hatiin ang board sa mga rectangle — isang numero sa bawat isa, at sinasabi ng numero ang laki nito!

Dinadala ng Shikaku Friends ang classic na Japanese logic puzzle na "Shikaku" kasama ang mga cute na hayop na magkakaibigan.

■ Dalawang simpleng rules
· Hatiin ang board sa mga rectangle.
· Isang numero lang ang laman ng bawat rectangle, katumbas ng dami ng cell nito.

■ Features
· I-drag para gumuhit, i-tap para burahin
· Gumagalaw at nagche-cheer sina Kitty, Panda, Bunny, Shiba at Bibe — pumili ng kasama mo
· 200 stages, at iisa lang ang sagot sa bawat puzzle
· Mangolekta ng dekorasyon sa bawat stage at ayusin ang village ng magkakaibigan
· Tapusin ang board para makita ang nakatagong larawan
· Bagong Daily Puzzle araw-araw na may 7-day streak rewards — i-share ang resulta mo
· Walang timer na nakaka-stress, puwedeng laruin offline
