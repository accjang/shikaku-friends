## description
按数字画出方块，把棋盘分割开来吧！

方块朋友是一款和可爱的动物朋友们一起挑战日本经典逻辑谜题“Shikaku（四角）”的游戏。

■ 规则只有两条
· 把棋盘分成长方形。
· 每个长方形里正好有一个数字，数字就是它的格数。

■ 游戏特色
· 拖动画方块，点一下就能擦掉
· 小猫、熊猫、兔兔、柴柴、小鸭会动来动去为你加油，还能选择同行的朋友
· 200个关卡，每道题都只有唯一解
· 每过一关收集道具，装扮朋友们的村庄
· 解完棋盘就会出现隐藏的图画
· 每天都有新的“每日谜题”，连续7天奖励，还能分享成绩
· 没有时间压力，离线也能玩
